# Templates

Use these templates only for durable project context or the requirement output hierarchy. User story files are generated by the `user-story-writing` skill, not by a separate project knowledge-base template.

## Wiki Templates

* [Project Overview Template](project-overview-template.md) - Project overview concept template.

## Requirement Output Templates

* [Initiative Index Template](initiative-index-template.md) - Initiative folder `index.md` template and canonical initiative page.
* [Epic Index Template](epic-index-template.md) - Epic folder `index.md` template and canonical epic page.
